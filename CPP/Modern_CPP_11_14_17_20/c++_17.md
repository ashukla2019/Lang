# 1. Structured Bindings

## Before C++17

```cpp
pair<int,string> p = {1,"Alice"};

cout << p.first << endl;
cout << p.second << endl;
```

---

## C++17

```cpp
C++ Structured Binding (Map and Tuple)

Structured binding (introduced in C++17) allows unpacking elements of objects into separate variables.

Syntax:

auto [a, b] = object;

1. With std::map

A map stores data as key-value pairs.

Without structured binding:

for (auto item : myMap) {
    std::cout << item.first << " " << item.second;
}


With structured binding:

for (auto [key, value] : myMap) {
    std::cout << key << " " << value;
}

key stores the map key
value stores the mapped value
2. With std::tuple

Without structured binding:

std::get<0>(tuple);
std::get<1>(tuple);


With structured binding:

auto [name, age] = tuple;


Each tuple element is assigned to a meaningful variable.

Benefits
Improves code readability
Avoids .first, .second, and std::get<>
Makes handling multiple return values easier

Example:

auto [quotient, remainder] = divide(10, 3);
---
```
# 2. if constexpr

Compile-time condition.

```cpp
C++ if constexpr Example

if constexpr (C++17) allows compile-time condition checking in templates.

#include <iostream>
#include <type_traits>
using namespace std;

template<typename T>
void print(T value)
{
    if constexpr (is_integral_v<T>)
        cout << "Integer\n";
    else
        cout << "Other Type\n";
}

int main()
{
    print(10);
    print(3.14);
}


Output:

Integer
Other Type


Explanation:

int → prints Integer
double → prints Other Type

if constexpr selects the correct branch at compile time.
```

Usage

```cpp
print(10);

print(3.5);
```

Output

```
Integer

Other Type
```

Unlike a normal `if`, the unused branch is discarded during compilation.

# 3. Fold Expressions

Before C++17

```cpp
sum(a,b,c,d);
```

required recursive templates.

---

C++17

```cpp
template<typename... Args>
auto sum(Args... args)
{
    return (... + args);
}
```

Usage

```cpp
cout << sum(1,2,3,4,5);
```

Output

```
15
```

# 4. std::optional

Represents

```
Value

or

No Value
```

Example

```cpp
#include <optional>

optional<int> divide(int a,int b)
{
    if(b==0)
        return {};

    return a/b;
}
```

Usage

```cpp
auto ans = divide(10,2);

if(ans)
    cout << *ans;
```

Output

```
5
```

# 5. std::variant

Type-safe union.

```cpp
variant<int,string> value;

value = 10;

cout << get<int>(value);

value = "Hello";

cout << get<string>(value);
```

Output

```
10

Hello
```

# 6. std::any

Can store any type.

```cpp
#include <any>

any value;

value = 100;

cout << any_cast<int>(value);

value = string("Hello");

cout << any_cast<string>(value);
```

Output

```
100

Hello
```

---

# Difference

| Feature | Types |
|----------|-------|
| optional | 0 or 1 value |
| variant | One of fixed types |
| any | Any type |

# 7. std::string_view

Avoids string copy.

Before

```cpp
void print(string s)
{
}
```

Copies string.

---

C++17

```cpp
void print(string_view s)
{
    cout << s;
}
```

Usage

```cpp
string str = "Hello";

print(str);

print("World");
```

No unnecessary copy.

# 8. Filesystem Library

```cpp
#include <filesystem>

namespace fs = std::filesystem;
```

Check file

```cpp
if(fs::exists("test.txt"))
{
    cout << "Exists";
}
```

Current directory

```cpp
cout << fs::current_path();
```

List files

```cpp
for(auto &f :
    fs::directory_iterator("."))
{
    cout << f.path() << endl;
}
```

# 9. Inline Variables

Before C++17

Header

```cpp

```

CPP

```cpp

```

---

C++17

```cpp
inline int x = 100;
```

Can safely define in a header without violating the One Definition Rule.

# 12. std::apply

Calls a function using a tuple.

```cpp
int add(int a,int b)
{
    return a+b;
}

tuple<int,int> t{10,20};

cout << apply(add,t);
```

Output

```
30
```

# 15. [[nodiscard]]

Warns if return value is ignored.

```cpp
[[nodiscard]]
int add(int a,int b)
{
    return a+b;
}
```

Wrong

```cpp
add(10,20);
```

Compiler may warn.

Correct

```cpp
int x = add(10,20);
```

Useful during development or conditional compilation.

# 17. std::shared_mutex

Header

```cpp
#include <shared_mutex>
```

Readers

```cpp
shared_lock lock(m);
```

Writer

```cpp
unique_lock lock(m);
```

Diagram

```
Reader 1

Reader 2

Reader 3

↓

All Together

-----------------

Writer

↓

Exclusive
```

Useful when reads are much more frequent than writes.

# 18. Parallel STL

Some STL algorithms can execute in parallel.

```cpp
#include <execution>

sort(
execution::par,
v.begin(),
v.end());
```

Policies

```text
seq

par

par_unseq
```

Note: Actual parallel execution depends on your compiler and standard library implementation.

# 19. std::byte

Represents raw memory.

```cpp
std::byte b{0x1F};
```

Useful in

- Binary files
- Networking
- Serialization
- Memory manipulation

Unlike `char`, `std::byte` is intended to represent raw bytes rather than text.
